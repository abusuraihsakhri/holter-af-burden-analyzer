Holter AF Burden Analyzer Local analysis

RR interval statistics, time-weighted tachycardia and bradycardia burden, and AF burden from verified annotations. Runs entirely in your browser.

Recording input

Provide consecutive RR intervals in milliseconds, or select a CSV file with rr_ms and optional af (1/0) columns. Use de-identified data.

Comma, whitespace, or newline-separated values. A pasted list is not considered ECG-verified AF.

Max 5 MB. A selected file takes priority over pasted intervals.

Analysis results

Provide an RR series, then select Analyze recording.

Interpretation and data-quality notes

    Research and educational use only. Irregular RR timing is not diagnostic of atrial fibrillation. Clinical AF requires ECG documentation and professional review. HRV derived from unfiltered RR values is not equivalent to normal-to-normal (NN) HRV. Long RR intervals may represent pauses, ectopic beats, or artefact. No clinical treatment advice is generated.

    Analysis and exports stay on this device; no file uploads or external APIs. Source: GitHub repository.
